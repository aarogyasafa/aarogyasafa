## Aarogyasafa API starter

This repository now includes an early FastAPI backend foundation for medical PDF text extraction and arithmetic checks for itemized bills.

- Setup and API usage: [docs/PROJECT_README.md](docs/PROJECT_README.md)
- Architecture and privacy notes: [docs/architecture.md](docs/architecture.md)
- API health: `GET /health`
- PDF text extraction: `POST /api/v1/documents/analyze`
- Bill arithmetic audit: `POST /api/v1/bills/audit`

This is a development starter, not a clinical decision-support or fraud-detection system. Do not commit real patient records, credentials, or sensitive documents.
